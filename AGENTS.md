# AGENTS.md — At All Services LLC Web

## Operating model
Intent → Mission → Build → Browser Proof → Review → Merge.

## Read before changing the site
1. `.repo-runtime/PROJECT_SOURCE_OF_TRUTH.md`
2. `DESIGN_AUDIT.md`
3. `QA_CHECKLIST.md`
4. latest mission under `.repo-runtime/missions/`

## Non-negotiable business boundaries
Do not invent reviews, ratings, licenses, insurance, certifications, warranties, response guarantees, staff size, customer count or extra service cities.

Do not convert 2023 into years of experience. Use **Serving Minnesota Since 2023**.

## Design boundary
A technically correct build can still fail. Do not call an iteration complete until real browser screenshots at all required breakpoints have passed visual review.

Do not fix weak art direction by adding cards, badges, gradients, giant type, gold blocks or animation.

## Conversion boundary
Call is primary. Request Service is secondary. WhatsApp/email are contextual tertiary channels.

Do not create dead CTAs. Do not use SMS wording unless SMS capability is separately confirmed.

## Deployment boundary
Do not add a canonical URL before a real final domain exists. Do not add analytics/account IDs without explicit values.
